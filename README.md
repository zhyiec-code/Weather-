# 晴雨天气

免费、无广告的天气网页 app（PWA）。

- 当前温度、体感、最高/最低、逐小时、10 天预报
- 未来一小时降雨（15 分钟分辨率）、紫外线、风、湿度、日出日落
- NOAA NEXRAD 雷达动画（IEM 瓦片 + OpenStreetMap 底图）
- 美国国家气象局（NWS）预报对照和天气警报

数据：Open-Meteo（best_match，美国用 NOAA HRRR/GFS 等）、api.weather.gov、Iowa Environmental Mesonet。

## 安装到 iPhone
Safari 打开网址 → 分享 → 添加到主屏幕。

## 桌面温度小组件
`widget/晴雨小组件.js` 是 Scriptable 脚本，见文件开头说明。
